# 토이블록 네이버 블로그 도우미 개인정보처리방침

시행일: 2026년 10월 30일 (v1.11.0 반영)

토이블록 네이버 블로그 도우미(이하 "확장 프로그램")는 사용자의 개인정보를 수집하거나 개발자에게 전송하지 않습니다.

## 1. 저장하는 정보
확장 프로그램은 아래 정보를 사용자의 크롬 브라우저 안(chrome.storage)에만 저장합니다. 이 정보는 개발자나 다른 곳으로 전송되지 않으며, 확장 프로그램을 삭제하면 함께 지워집니다.
- 단축키·글자 모양·화면 표시 등 설정값
- 분석 패널을 연 날의 블로그 방문자 수 기록(블로그별)
- 검색 노출 확인 결과(글 번호, 검색 순위, 확인 시각)
- 최신 버전 확인 결과와 온라인 설정
- 이웃 소통 기록(열어 본 글·댓글을 등록한 글의 블로그ID/글 번호와 시각, 최근 30일), 같은 문장이 반복되지 않게 하는 템플릿 사용 기록
- 이웃 추가 도우미 기록(이웃 추가 창을 연 블로그ID와 날짜, 신청 결과, 하루 횟수 — 하루 한도와 목록의 "신청함" 표시에만 씀)과 사용자가 쓴 신청 메시지 문구
- 키워드 추천용 블로그 점수(검색 결과 블로그ID별 점수, 12시간 동안 재사용)
- 사용자가 넣은 AI API 키(확장 전용 보관함 IndexedDB — 동기화되지 않음)

크롬 동기화를 켜 두었다면 설정값은 사용자의 구글 계정 동기화 기능으로 다른 기기의 크롬에 복사될 수 있습니다.

## 2. 네트워크 요청
확장 프로그램은 기능을 위해 다음 주소에 요청을 보냅니다. 어느 요청에도 사용자의 개인정보는 담기지 않습니다.
- **m.blog.naver.com**: 사용자가 보고 있는 블로그의 공개 정보(블로그 이름, 방문자 수, 이웃 수, 글 목록)를 읽습니다. 이웃 소통의 키워드 검색을 하면 검색 결과에 나온 블로그의 같은 공개 정보를 읽어 추천 점수를 계산합니다.
- **search.naver.com**: 사용자가 "노출 확인"을 누를 때 글 제목으로 네이버 블로그 검색을 합니다. 로그인 정보(쿠키)는 보내지 않습니다.
- **raw.githubusercontent.com**: 최신 버전 번호와 온라인 설정(JSON 데이터)을 읽습니다.
- **query.blog.naver.com, section.blog.naver.com**: 사용자가 이웃 소통 탭을 열 때, 로그인한 사용자의 네이버 이웃 새 글 목록을 읽습니다.
- **AI 회사(선택)**: 사용자가 설정에서 제미나이(generativelanguage.googleapis.com)·클로드(api.anthropic.com)·GPT(api.openai.com)·OpenRouter(openrouter.ai) 중 하나를 고르고 자신의 API 키를 넣은 경우에만, 사용자가 연 글의 제목·소제목·본문 일부(최대 2,500자)와 블로거 닉네임을 그 회사로 보내 댓글 초안을 받습니다. 보낸 내용의 처리는 각 회사의 정책을 따르며, 제미나이 무료 등급은 보낸 내용이 구글 제품 개선에 쓰일 수 있습니다.
- **AI 키 만들기 화면(선택)**: 사용자가 "키 받으러 가기"를 누르면 그 회사의 키 화면(aistudio.google.com, platform.claude.com, platform.openai.com, openrouter.ai)을 새 탭으로 열고 그 탭에만 안내 줄을 띄웁니다. 사용자가 키를 복사하거나 안내 줄에 붙여 넣으면 키 모양인 글만 확장의 키 보관함에 저장하고, 그 밖의 화면 내용은 읽거나 보내지 않습니다.
- **OpenRouter 로그인(선택)**: 사용자가 "로그인하고 바로 연결"을 누르면 OpenRouter 로그인 창을 열고, 사용자가 허용하면 받은 코드로 openrouter.ai에서 사용자의 API 키를 받습니다.
- **raw.githubusercontent.com(폴더 설치본)**: 사용자가 "지금 업데이트"를 누르면 새 버전 파일(zip)을 받아, 사용자가 고른 설치 폴더에 바꿔 넣습니다.

댓글과 서로이웃 신청은 사용자가 버튼을 누른 글·블로그에만 보냅니다. 댓글 초안은 입력칸에 채워지거나 클립보드에 복사되고, 사용자가 네이버 [등록]이나 댓글 카드의 [✓ 등록 + 서로이웃 신청]을 누를 때 그 글에 등록됩니다. 서로이웃 신청은 사용자가 누른 버튼으로 열린 네이버 이웃 추가 창에서, 사용자가 설정한 신청 메시지로 그 블로그 한 곳에 보냅니다.

## 3. 외부 링크
확장 화면 하단의 쿠팡 배너는 사용자가 누를 때에만 쿠팡 파트너스 링크로 이동합니다. 이동 이후의 정보 처리는 쿠팡의 개인정보처리방침을 따릅니다.
이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
