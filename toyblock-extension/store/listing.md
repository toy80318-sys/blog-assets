# 크롬 웹스토어 등록 자료

대시보드의 각 칸에 그대로 붙여 넣으면 됩니다.

## 이름
토이블록 네이버 블로그 도우미

## 요약 (132자 이내)
네이버 블로그 글쓰기 단축키(엔터+소제목·인용구)와 상단 버튼, 블로그 점수·검색 노출·글자 수 분석 패널을 한 번에.

## 카테고리
생산성 (Productivity)

## 언어
한국어

## 상세 설명
토이블록 네이버 블로그 도우미는 네이버 블로그를 쓰고 관리하는 시간을 줄여 주는 확장 프로그램입니다.

■ 글쓰기
· Ctrl+Shift+1: 엔터로 새 줄을 만들고 그 줄을 바로 소제목으로
· Ctrl+Shift+2: 선택한 문단을 인용구 서식으로
· Ctrl+Shift+3: 버티컬 라인 등 원하는 모양의 인용구 블록 삽입
· 글쓰기 화면 상단에 같은 기능의 버튼 줄, 글자를 드래그하면 뜨는 미니 팝업
· 단축키마다 글꼴·크기·굵기·색을 함께 적용하도록 설정

■ 블로그 분석 (블로그를 볼 때 왼쪽에 작게 붙는 패널)
· 총 방문자·오늘 방문자·이웃·전체 글
· 검색 노출·발행 꾸준함·최근 발행·독자 반응·방문자로 계산한 100점 블로그 점수
· 최근 글 30편의 제목 검색 순위로 보는 검색 노출 지수(최적·활성·주의·누락)
· 4주 발행 분석(요일·시간대·간격), 인기글
· 글 하나의 글자 수(공백 제외 포함)·문단·이미지·링크·소제목·인용구·핵심 키워드

■ 블로그 점수 가이드
· 점수가 낮은 항목을 올리는 방법을 정리한 페이지로 바로 연결

모든 설정은 내 크롬에만 저장되며, 개발자에게 전송되는 개인 정보는 없습니다.
화면 하단의 쿠팡 배너는 쿠팡 파트너스 링크로, 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

## 단일 목적 (Single purpose)
네이버 블로그 글쓰기와 블로그 관리를 돕는 도구입니다. 글쓰기 화면의 서식 단축키·버튼과, 블로그 화면의 분석 패널을 제공합니다.

## 권한 사용 이유
| 권한 | 이유 |
|---|---|
| storage | 단축키·글자 모양·패널 위치 설정과 블로그별 방문자 기록, 노출 확인 결과를 사용자의 크롬에 저장합니다. |
| alarms | 6시간마다 최신 버전 정보와 온라인 설정(네이버 에디터 버튼 이름)을 확인합니다. |
| 호스트: blog.naver.com, *.blog.naver.com | 글쓰기 화면에 단축키·버튼을 붙이고, 블로그 화면에 분석 패널을 띄우며, 공개 블로그 정보(방문자·글 목록)를 읽습니다. |
| 호스트: search.naver.com | 사용자가 "노출 확인"을 누를 때 글 제목으로 네이버 블로그 검색을 해 순위를 확인합니다. |

## 원격 코드 사용 여부
사용하지 않습니다. 확장이 내려받는 것은 최신 버전 번호와 버튼 이름 같은 JSON 데이터뿐이며, 실행 코드는 모두 패키지 안에 들어 있습니다.
