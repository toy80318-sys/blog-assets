# UTLC 커뮤니티 — 언리얼테크로그 레딧형 커뮤니티 + 3D 모델 마켓

unrealtechlog.com(WordPress)을 레딧과 같은 구조의 커뮤니티로 바꾸는 플러그인입니다.
기존 블로그 글은 그대로 두고, 그 위에 게시판·추천/비추천·댓글 스레드·모델 판매 기능을 더합니다.

## 설치 (wp-admin에서 5분)

1. `dist/utlc-community.zip` 파일을 내려받습니다.
2. **wp-admin → 플러그인 → 새로 추가 → 플러그인 업로드**에서 zip을 올리고 **활성화**합니다.
3. 활성화하면 자동으로 다음이 진행됩니다.
   - 게시판 4개 생성: `r/free` 자유게시판, `r/qna` 질문·답변, `r/market` 모델 마켓, `r/techlog` 테크로그(공식)
   - 기존 블로그 글 전체를 `r/techlog`에 연결 (글 주소·본문·댓글·이미지는 바뀌지 않습니다)
   - 이전에 만들었던 커뮤니티 글(`utl_item`, 게시판 free/questions/tutorials/showcase/jobs)을 새 게시판으로 옮김
   - 회원가입 허용(`users_can_register`) 켜기
   - 사이트 첫 화면을 커뮤니티 홈으로 전환 (설정에서 끌 수 있음)
4. **설정 → 고유주소**에서 한 번 **변경사항 저장**을 눌러 주소 규칙을 새로 고칩니다.
5. **WP Super Cache**를 쓰는 경우, **설정 → WP Super Cache → 고급 → 캐시하지 않을 주소**에 다음을 추가합니다.
   `/utlc-pay/`, `/utlc-download/`, `/checkout/`, `/submit/`, `/login/`, `/join/`
6. **wp-admin → 커뮤니티 → 개요**에서 "기존 데이터 점검" 결과를 확인합니다.

## 주소 구조 (레딧과 동일)

| 주소 | 내용 |
|---|---|
| `/` (또는 `/community/`) | 전체 피드 — 인기 / 최신 / 추천(기간별) |
| `/r/{게시판}/` | 게시판 피드 |
| `/r/{게시판}/comments/{번호}/{제목}/` | 글 상세 + 댓글 스레드 |
| `/submit/`, `/r/{게시판}/submit/` | 글쓰기 (글·이미지·링크·모델 판매) |
| `/u/{아이디}/` | 프로필 (글, 댓글, 판매 모델, 구매내역, 판매관리) |
| `/communities/` | 전체 게시판 목록 |
| `/login/`, `/join/` | 로그인, 회원가입 |

## 게시판 늘리기

**wp-admin → 커뮤니티 → 게시판**에서 새 게시판을 추가합니다. 이름·슬러그(주소)·설명 외에
유형(일반/마켓/공식), 아이콘(이모지), 색상, 규칙, 말머리(플레어), 글쓰기 권한, 정렬 순서를 정할 수 있습니다.
추가하는 즉시 `/r/{슬러그}/` 주소와 왼쪽 메뉴에 나타납니다.

## 모델 판매

- 회원이 `r/market`에 **모델 판매** 글을 올리면(가격, 라이선스, 포맷, 폴리곤 수, 엔진 버전, 모델 파일 또는 외부 다운로드 링크, 미리보기 이미지, 선택 GLB 3D 미리보기) 관리자 **판매 심사** 후 공개됩니다.
- 모델 파일은 `wp-content/uploads/utlc-private/`에 임의 이름으로 저장되고 직접 접근이 차단됩니다. 구매자·판매자·관리자만 `/utlc-download/{번호}/`로 받을 수 있습니다.
  - 더 안전하게 하려면 `wp-config.php`에 웹 루트 밖 경로를 지정하세요: `define( 'UTLC_PRIVATE_DIR', '/home/계정/utlc-private' );`
- 결제 수단
  - **무료(0원)**: 바로 다운로드
  - **무통장입금**: 설정에 계좌 입력 → 구매자가 입금자명 입력 → 관리자가 **주문 관리**에서 "입금 확인"
  - **토스페이먼츠 카드결제**: 설정에 클라이언트 키·시크릿 키 입력 후 켜기 (테스트 키 `test_ck_…`/`test_sk_…`로 먼저 시험)
- 수수료율(기본 20%)만큼 뺀 금액이 판매자 수익으로 쌓이고, 판매자는 **판매관리** 탭에서 정산을 요청합니다. 관리자는 **정산 관리**에서 이체 후 "지급 완료"를 누릅니다.

### 운영 전 확인할 것 (법·결제)

- 다른 회원의 상품을 파는 **통신판매중개** 구조입니다. 통신판매업 신고, 중개자 고지(설정의 "마켓 고지문"), 개인정보처리방침·이용약관 페이지를 준비하세요.
- 토스페이먼츠 실결제는 사업자 계약이 필요합니다. 여러 판매자에게 대금을 나눠 주는 구조는 토스페이먼츠 "지급대행" 등 별도 계약을 검토하세요.
- 판매자가 Fab/마켓플레이스 등에서 산 에셋을 재판매하는 것은 라이선스 위반입니다. 심사 단계에서 확인하세요.

## 꼭 지킬 것

- 이 사이트의 미디어(`wp-content/uploads`)는 다른 블로그(앱노트·씬노트·짠테크노트·혜택체크 등)가 이미지 주소로 직접 쓰고 있습니다. **미디어 삭제·업로드 경로 변경을 하지 마세요.** 이 플러그인도 기존 파일을 건드리지 않습니다.
- 플러그인을 비활성화해도 글·댓글·주문 데이터는 지워지지 않습니다.
